Plate book

The benchmark battery as one sheet: every structure drawn, and every convergence sweep plotted against the reference it is judged on. Everything is rendered from the repository's own data — geometry straight out of structures.py, numbers out of the convergence run and the Moose reference — so no figure can drift from what it claims to draw. Rebuild it with python benchmark/make_plate_book.py.

Part A

Drawing the structures

One style for all thirteen, plus the atlas as an opener. The decisive change from the first round: air is absent rather than grey. The gaps between ridges and pillars are open space, a perforated film is cut through to its substrate, and a free-standing case gets a dashed phantom half space instead of a solid block — so what you see filled is exactly what is material.

S2structures

Every structure as a solid isometric unit cell

Ridges, pillars and cylinders are real prisms with shaded faces and depth-sorted overlap, not a textured block. A hole array is drawn as a pit you look into: far walls in shadow, substrate at the bottom. E is drawn along the axis the polarization actually selects, so TE-along-the-grooves versus TM-across-them reads as geometry rather than as a letter you have to decode.

Part B

Drawing the convergence

Both convergence plates drop the red/green encoding: colour is now the factorization rule and dash plus marker the codebase, on the argument that the story this battery tells is direct-versus-faithful rather than fork-versus-ikarus. Both Laurent columns therefore collapse onto one grey — which is itself the claim that the direct rule behaves identically in both codes. The palette is Okabe-Ito, so the figures survive colour-blind readers and greyscale printing.

C2cost

The cost staircase: the best error a wall-time budget can buy

Faint markers are the raw measurements; the thick step is the running best — the honest answer to “with 100 ms, how close can I get?”. Monotone by construction, so the oscillation that makes a plain error-vs-time scatter unreadable becomes a flat tread instead of a scribble. A flat tread means spending more buys nothing.

C4two axes

Signed deviation on a symlog axis

One linear axis cannot hold both the low-order transient and the 1e-4 endgame, which is why the raw figure needs a _tight twin. A symlog axis holds both: outside ±1e-4 it is logarithmic and you read the transient and the sign of the approach; inside the band it goes linear and the endgame is legible in the same panel. Two variants — against retained orders and against wall time — and Moose is now on both, since the scripted run records a t_solve per point. Where a case is judged against Moose its black curve is self-convergence, which the panel says; on D1 and D2 it is a genuine third-code accuracy curve.

C1digits

The digit map

One row per code+rule, one colour step per correct digit of R, ▼ at the first sustained |ΔR| ≤ 1e-4. Fastest glance of anything here — group C is visibly a wall of blue, nobody converges — but it throws away the sign and the shape of the decay, which is what C2 and C4 keep — so it reads fastest and tells least.

How this page is made

One command — python benchmark/make_plate_book.py — renders the seven plotters below and inlines every figure into this file. Shared code sits in benchmark/: viz_palette.py (materials, colours, physics badges, geometry pulled from structures.py), viz_iso.py (the isometric solid renderer) and viz_conv.py (tidy arrays, references, Moose sweep parsing, the running-min envelope and the sustained-arrival rule that matches conv_run.py).

What to keep in mind reading this

  • Reference drift, measured at build time: {{META:REFDRIFT}}. conv_results.json bakes in the reference each case was judged against when it was solved, while moose_reference.json keeps improving independently. These plates re-read the live Moose value for any case judged against Moose, so where that list is not empty they and plot_conv.py — which keeps the baked value — disagree until the sweep is re-run.
  • Self-convergence is not accuracy. Where a case is judged against Moose, the black Moose curve reaches its own reference by construction: it says how fast Moose settles, not how right it is. Only D1 and D2, judged against Ikarus's normal-vector value, carry a genuine third-code accuracy curve.
  • The older figures still exist. conv_accuracy_vs_time.png and moose_compare_raw*.png are what C2 and C4 were built to replace; plot_conv.py and plot_moose.py still emit them, and this page does not depend on them.
